# 製品コンテキスト（Product Context）

## repack-tool が解決する問題（実装済み）
圧縮ファイル（例: 1つの 7z に FolderA/FolderB が混在）を手作業で解凍し、
フォルダ毎に zip 圧縮し直す作業は反復が多く、パスワード・分割巻・文字化け等の
例外処理で事故りやすい。この一連の処理を自動化する。

### 提供する体験
- 入力フォルダと出力フォルダを指定するだけで再帰処理（既定 ON）
- パスワード付き圧縮は UTF-8 辞書（1行1件）で自動試行
- 分割・破損は事前チェックでスキップ継続（1件失敗で止まらない）
- 出力は `out/<入力相対親>/<アーカイブ名>/` 配下にミラー再現。同名は `_001` 連番で上書き禁止
- 日本語ファイル名・ロングパス対応。7z.exe があれば rar 等も処理（無ければスキップ）
- GUI は CLI 相当の全設定＋進捗バー＋推定時間表示。D&D は任意依存 `tkinterdnd2` 導入時のみ有効

### 品質面の保証
- 終了コードで結果判別: 0=全成功 / 2=一部スキップ・失敗 / 1=致命的エラー / 130=中断
- ログにパスワードを出さない・走査順は相対パス昇順で再現性を担保
- 機密らしき名前は警告のみ、`--exclude-pattern` で除外可能

## asset（第2機能・実装済み）が目指したもの
- 指定起点フォルダを読み取り、**全階層のフォルダを 1 フォルダ 1 行**で
  直下/配下のファイル数・サイズ・最新更新日時を集計した資産台帳を出力（達成）
- 既定 CSV＋任意 HTML/MD。合計行あり（独立計算・二重計上なし）（達成）
- 読み取り専用であり、既存データを壊さない安心感を提供（達成）
- 想定規模: 10万フォルダ/CSV 10万行（README・マニュアルに性能目安を記載済み）

## ユーザー
- 単一ユーザー（開発者本人）の Windows 端末上で完結する個人ツール
- 操作は GUI メイン（TOP 画面 `suite_top` から各機能へ遷移）＋自動化用の CLI

## 成功の基準
- repack: E2E サンプル（T01〜T22 相当）で期待通りの分類/命名/終了コードになること
- asset: 11 列・合計行・ソート安定性・BOM/CRLF 等の確定仕様どおりの出力
- 旧エントリ `python -m repack_tool` が現行動作と同一であること（Q11=A）
